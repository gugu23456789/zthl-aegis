## 0. 为什么需要（自伤根因）

**F-REV-50（实测）**：每轮质询的新增缺陷条数**不衰减**（均值 ~10），本轮 **18 条中 5 条（28%）可追溯到前两轮的修复动作本身**。
自伤是**结构性**的 —— 三条件同时成立时必然发生：

| # | 放大条件 | 证据（本仓） |
|:--|:--|:--|
| **A1 无节流** | 修复动作**不受编辑次数限制约束** | `edit_budget` 只在 `gk_advance` **进入 standing 节点**时注入（`scripts/gk_advance.py` 的注入段），live state 无该键 ⟹ 守卫读 `-1` ⟹ 不阻断不扣减；**节点外的计划文档编辑完全不受限**（见 assessment **F-REV-45 REV-2**） |
| **A2 修复即改写** | 修复方式是**改写已定案段落** | 判据 #10 样例改写 ⟹ 引入**假红**；`[ASSUMPTION-5/6/7]` 新增 ⟹ 与 §7 **撞号** |
| **A3 单侧 red-first** | 只验「新判据能过」，不验「旧判据在新文档上仍过」 | 同一病按**三个精度层级**复制：判据**样例层**（假绿）→ **前提层**（假红）→ **样例改写层**（假红） |

> **推论**：只要 A1-A3 不消除，**继续修条 = 继续制造新条**。故对策不是"修得更仔细"，而是
> **把可机检的部分前移到落笔前**（本网），**把不可机检的部分留在 R 侧**（plan-refinement）。

## 1. 残差数学：W 侧只有一个可控量

### 1.1 R 侧（评判侧）公式 —— 已钉定，本网不重复定义

来源：`2026-09-13-crossreview-optimization-plan.md §13.5` + `2026-09-14-convergence-evaluator-subplan.md §1`。

```text
r̂ = (μ_N / μ_0)^{1/N}                 # **stock 比**：相邻轮 μ_n/μ_{n−1} 的几何均值（**判决量唯一**；禁 flow 比 b̄/ā —— 口径史见子计划2 §1.3）
μ̂₀ = |{f : f.status ∈ {open, in_progress}}|   # 残留缺陷项数
μ_tgt = 计划规定的残留上界（默认 1；0 = 清空）

r̂ < 1 :  N* = ⌈ ln(μ̂₀ / μ_tgt) / ln(1 / r̂) ⌉    # 收敛轮数
r̂ ≥ 1 :  N* = ∞ ⟹ 须外部熔断（冻结扩张 b→0）

噪声区间：由 r̂ ± δ 给 [N*_hi, N*_lo]，判决用 **N*_hi**（保守上界）
前提门：T 未冻结（无 §13.6 式 T* 登记）⟹ 拒出 N*，报 T_NOT_FROZEN（前提门须给 producer）
```

### 1.2 W 侧对偶：写侧唯一可控量是 **引入率 `β`**

`ā`（消解）由质询挖，`b`（引入）由修复产生 —— 但 `b` 的**源头是写法**：
判据不可机检 ⟹ 每次修都得**改写散文** ⟹ 顺手引入新条。故：

```text
β ≜ 写侧引入率（每单位"计划文本改动"产生的新 finding 数）
W-协议工程目标：最小化 β  ⟹  把 r̂ 从 ≈1 推过 <1
```

**三个必须钉死的前提**（否则重蹈旧式「不可评估」）：

| # | 前提 | 钉定 |
|:--|:--|:--|
| **P1** | `b̄/ā` 口径 | = finding 计数（`gk_finding.py` 状态机 + journal 可数），**非**反解 `s` |
| **P2** | `T` 冻结 | 无 §13.6 式 `T*` 登记 ⟹ 拒出 `N*`（`T_NOT_FROZEN`） |
| **P3** | **自指** | **本计划自身的 `b̄` 也计入** —— 用自己的公式判自己（S12：本计划 `b̄/ā ≈ 1` ⟹ 应被自己的 `CONVERGENCE_BUDGET_EXCEEDED` 拒入队） |

> **P3 的意义**：这不是修辞。S12 已实测：subplan2 两轮质询产出 `D1-D7`(7) + `G1-G10`(10)，`b̄` 不衰减 ⟹ `r̂ ≥ 1`。

## 2. 判定系数 λ（W 侧自评 vs 人类真值的校准）

### 2.1 为什么必须有 `λ`（而不是直接信机检）

**F-REV-48 实测**：`7 维共识 54.3` 而 **`s_G3 > s_G1`**（污染臂得分**反而更高**）⟹ 自评分轴 `s` **不是有效 reward**。
F-REV-50「分数轴反证」：`7 维 33.6 → 51.63`（↑）而 `b̄` **不变**、κ `2/2 → 1/4`（↓）⟹ **"提分"不能作为"修好"的证据**。

⟹ 机检/评分给的是**自评**，人类裁决给的是**真值**，两者必然有偏 ⟹ 需要**校准系数**。

### 2.2 定义

```text
Q_W = W 侧机检放行率 = (# 计划 lint 通过) / (# 计划跑过 lint)
Q_H = 人类裁决通过率 = (# adjudicate 批准) / (# 裁决)

λ = Q_H / Q_W                      # 校准比
λ < 1 ⟹ 机检放行了人类否决的（假绿）⟹ 自动收紧
λ → 1 ⟹ 机检与真值对齐
```

| λ 区间 | 含义 | 处置（**阈值待标定，见 §9.6；未标定前不作硬阻断**） |
|:--|:--|:--|
| `λ ≥ 0.9` | 机检与真值对齐 | 维持 |
| `0.7 ≤ λ < 0.9` | 机检偏松 | 收紧：`L-CRITERION`/`L-CONSUMER` 的 medium 升 high |
| `λ < 0.7` | 机检**结构性**偏松 | **停下重设计判据**（不是加阈值） |

> **可证伪判据**：收紧后重测，`λ` 应上升；若 `λ` 不升而 high 命中暴增，则判据有假阳性 ⟹ 登记并回退。
> **数据源已存在**：`adjudicate --verdicts`（真值）+ `gk_plan_lint.py` 退出码（自评），**零新增采集**。

### 2.3 RL 对位（"类似 RL"精确在哪）

| RL 概念 | 本域 | 载体 |
|:--|:--|:--|
| policy `π` | **怎么写** | 本网（PW-SN） |
| value `V` | **怎么判** | plan-refinement + MoA 7 维 |
| reward（真值） | 人类裁决 | `adjudicate` |
| **TD-error** | `Q_H − Q_W` | `λ = Q_H/Q_W` |
| 收敛率 | `r̂ = (μ_N/μ_0)^{1/N}`（stock 比） | §1 |
| 学习率 | **无**（禁无上限重跑） | ember §17 止损规则（连续 2 轮增幅 <5 熔断） |

> **边界**：`r̂<1` + `N*` 是**势函数单调下降 ⟹ 收敛**（Lyapunov/折扣收敛），**不是** reward。
> 真正"像 RL"的只有 `λ` 这一格（TD-error 校准）。**不得**把两者混称为同一个东西。

## 3. 三段闭环（对齐安全网 §2.2）

| 段 | 动作（机械可执行） | 拦截的失败 | 时点 |
|:--|:--|:--|:--|
| **① 落笔前** | 每条判据先跑**现状**（red-first，取实际输出） | 假绿（判据本来就过）/ 假红（判据本来就不过） | **设计质询前** |
| **② 落笔前** | 每个新开关 `rg` 全仓 + 给「省略时行为 = **原行为**」 | 幻影开关（全仓 0 命中） | **设计质询前** |
| **③ 落笔后** | **每次修复立刻复扫**（env / 开关 / **假设编号** / 消费者 / 行锚）+ 跑**双向 red-first** + **跑机检** | 修复自伤（F-REV-50） | **每次提交前** |

**双向 red-first（③ 核心，防 A3）**：
- 新判据 × **旧文档** ⟹ **必须失败**（否则判据没测到新东西 = 假绿）
- 旧判据 × **新文档** ⟹ **必须仍通过**（否则修复顺带改坏旧面 = 假红）

**禁止**：修复时**顺带改写已定案段落**（防 A2）。改写已定案段落须**显式登记为变更**并重跑该段判据。

### 4.1 行锚怎么写才**可自校验**（D2 落地形态）

`L-ANCHOR` 的 ① 行号越界 是**被动**检查（只判"行号是否超出文件"）；**真正的判据 = 断言字面值须与锚点同源**。
`gk_plan_lint.py` 只认**三种作者显式绑定**（高置信，宁缺毋滥）—— **按此书写即可被自动守护**：

| # | 形态 | 写法（`<file>`＝仓内路径，`<sym>`＝符号名） | 校验 |
|:--|:--|:--|:--|
| ① | **同 backtick 绑定** | `` `<file>:<line> <sym>` `` | `sym` 须落在该行；否则报**最近命中行 + `offset ±N`** |
| ② | **符号前置绑定** | `` `<sym>`（`<file>:<line>`） `` 或 `` `<sym>` 在 `<file>:<line>` `` | 同上（`sym` 与锚点须在**同一行、相邻**） |
| ③ | **裸符号锚** | `` `<sym>:<line>` `` 或 `` `<sym>`（**`: <line>`**） `` | `sym` 须在仓内**唯一**定义；该行须落在其**本体**内（`def` 行 ~ 下一个 `def` 行 − 1） |
| ②′ | **紧随代码片段** | `` `<file>:<line>`（… `break 2` …） `` | 片段须含字母数字 + 空格/运算符（纯运算符如 ` + ` 不算） |

**不覆盖**：裸 `:1234`（无符号）、`L1234` 前缀、无断言字面值的锚 —— 它们**不是"已校验"，而是"无依据可校验"**（§6 边界）。
**漂移检测**：命中行 ≠ 锚点行时，优先取锚点**之后**的最近命中（插入改行是常见形态），并报 `offset`（如 `+15`）。

## 5. 可证伪成功判据

> **PW-SN 生效 ⟺ 质询命中收敛到语义项（D5/D6 深层），机检项（D1-D4 + 结构 + 判据）命中 = 0。**
> **校准达标记 ⟺ `λ → 1`。**

- **可证伪点**：对一份**未跑本网**的计划跑 `gk_plan_lint.py`，应得 **high/medium > 0**；
  按本网补齐后重跑，应得 **high/medium = 0**（info 级的**外部引用**不计）。
- **反例即证伪**：若某机检项在"补齐后"仍报 high/medium，则要么 W 产物定义有误，要么 linter 有假阳性 —— **两者都必须登记**（不许"改判据让它过"）。

## 6. 落地状态（实测，2026-09-14）

**首轮实测结论（2026-09-14，过程记录见 `docs/plans/`）**：两子计划各 1 条 medium，**均为真阳性**
（一为「自称可机检但未给命令」，一为「消费者数 = 幻影影响面」）；按本网补齐后双双 **0 high/medium**。
单轮估算：命中中 **~61%** 可纯机检拦下（`rg`/行比对/清单差集）、**~28%** 需「判据对现状跑一遍」、真正语义判断 **~6%**
⟹ **~89% 的命中可在落笔前消掉**，这是自伤率下降的主要杠杆。

**`L-ANCHOR` v2 的由来（本仓自伤实例）**：一次提交在 `gatekeeper-cli.sh` 插入 15 行 ⟹ 其后**全部行锚**下移 15；
**v1（仅判行号越界）对 6 处全假阴**（行号仍在文件内）⟹ v2「断言字面值须与锚点同源」才把这类**静默漂移**变成可机检。

**linter 已知边界（实测登记，勿在未标定时稀释）**：

| 类 | 现象 / 处置 |
|:--|:--|
| **L-CONSUMER 假阳** | 命中**撤回句**（句内含「实测/幻影/曾称」等更正标记）⟹ 本次靠**改写表述**消除；**拟加规则**：同行含更正标记 ⟹ 降 `info`（**须先标定，勿先落地**） |
| **L-CONSUMER 假阴** | 缺「被」字则漏检（「是 N 消费者」形态）⟹ 拟扩正则；**同上，先标定** |
| **L-ANCHOR info** | 已声明的外部参照仍报 info ⟹ **设计如此**（info 非阻断：不可能在仓内核外部行号） |
| **L-ANCHOR 覆盖** | **仅** §4.1 三形态可自校验；裸 `:1234`、`L1234`、无断言字面值的锚 = **"无依据可校验"≠"已校验"** ⟹ 提覆盖率靠作者按 §4.1 书写 |
| **L-ANCHOR 假阳（①b/③b）** | markdown **表格邻格**符号被误当断言绑定 ⟹ **已收紧**：①b/③b 间隔**禁 `｜`**；代价 = 表格内该形态失效 ⟹ 改用 ①/③ 同 backtick |
| **L-ANCHOR 静默①字面值未逐字** | 断言字面值不在所锚文件出现时原为**静默 return**（防假阳）⟹ 打错字与真错锚一并逃逸；**已改**为 info「**不可校验 ≠ 已校验**」（F-REV-67 ①），用例 `test_anchor_symbol_absent_from_file_is_info_not_silent` |
| **L-ANCHOR 静默②裸符号锚多义** | `len(defs)==1` 前置 ⟹ 同符多实现时早退不报；**已改**：`>1` ⟹ info「不可判定 + 点出多义」，`==0`（外部/散文）保持静默（F-REV-67 ②） |
| **L-ANCHOR ↔ anchor_existence 双源** | 两处各自维护锚正则 ⟹ **已收口**为 `iter_anchor_refs(text, loose)` 参数化单源（strict = `L-ANCHOR`；loose = doc-align 原语义，召回面不变）。**⚠ 须「函数级」单源**：只 `import` 常量再自跑 `finditer` 是**常量级假单源** ⟹ 守门用例 `test_doc_align_single_source_is_function_level_not_constant`。余项 = F-REV-68 |

**`L-META` 的首扫教训（已实装，勿回退）**：META 写成**竖线分隔的多字段单行**会被 `_parse_meta` 静默判为「缺字段」
（协议只允许「块格式」或「逐字段 inline」），而 bash 侧 `_read_plan_metadata` **完全委派**该解析器 ⟹ 该计划在 5 层搜索中被当作
**残缺 META 跳过**（潜伏治理缺陷）。**修法 = 改规范 inline（同 1 行 ⟹ 零锚漂移）**。`L-SYMBOL` 首扫 0 命中（符号表内无撞车）。

**与 `gk_doc_align.anchor_existence` 的分工裁决**：两者都校验 `path:line`，但立场不同 —— `L-ANCHOR` = **写侧门**（全仓 + 断言同源 + 漂移 `offset`，high/medium 阻断）；
`anchor_existence` = **审计/CI 面**（只扫 `docs/plans/*.md` + 邻域词命中，WARN 不阻断）。**`L-ANCHOR` 为超集**，审计面保留（非冗余）；
锚实现**已函数级单源**（`iter_anchor_refs(line, loose=True)`）⟹ 消「双正则各自漂移」。**分工边界（防第二事实源）**：
**漂移检测只在 `anchor_existence`** / **可判定断言只在 `L-ANCHOR`** —— 本网**不实现**任何模糊/邻域匹配。
**⚠ 现存缺口**：`anchor_existence` 的**链接型锚**假阳成规模（markdown URL 落 `±40` 邻域 ⟹ 路径碎片被当断言词）⟹ 已登记 **F-REV-68**；
**收口前仓级漂移面不可作权威**，也**不得**据此把锚漂移升 high。

**待办**：`λ` 阈值表（§2.2）按 §9 跑数标定；两条 `L-CONSUMER` 边界待标定后再决定是否收口；F-REV-68 假阳收口 + `_verify_literal`「近似命中」档。

- **阻断权仍只归 `L-ANCHOR`**：本补充**不移交**阻断权，维持 §6 已立分工「漂移检测只在 `anchor_existence`（WARN 不阻断）/ 可判定断言只在 `L-ANCHOR`（high/medium 阻断）」—— 避免第二事实源。

## 9. 验证计划（怎么跑数把 `λ` 标定）

> **纪律**：流程**冻结不改**（派发正本 = `2026-09-14-convergence-evaluator-subplan.md §0.1.1`，N1-N9 约束原样适用）——
> 本网只**新增 3 个记录量 + 1 个停止规则**，不动流程本身。

**每轮记录 3 量**：机检命中 high/medium（`gatekeeper-cli.sh plan-lint <plan>`，应**单调 → 0**）／
`r̂ = (μ_N/μ_0)^{1/N}`（`gk_finding.py` journal 的 finding 计数）／`λ_k = Q_H/Q_W`（`adjudicate --verdicts` + plan-lint 退出码）。
`N*_hi` 由 `gk_convergence_estimator` 产出，不属本网。

**停止（三条全满足）**：7 维共识 ≥ 75；机检 high/medium = 0；`r̂ < 1`（`N*_hi ≤ GK_CONV_MAX_ROUNDS`，默认 3）。
**熔断**：连续 2 轮 7 维增幅 < 5 ⟹ 回人类裁决，禁再重跑。
**假绿/假红双向登记**：7 维↑ 而机检不降 = 假绿；机检清零而 7 维不动 = 过度收紧（假阳）⟹ 登记并回退判据，**不许"改判据让它过"**。

**`λ` 标定推进**：`n < 10` 次裁决**只记录不门控**；`n ≥ 10` 启 `C2 = 0.75` 起步；`λ` 稳定偏离切 **C4（Wilson 下界）**。
**口径铁律**：`Q_H`/`Q_W` 必须**同轴**（只计机检项类 D1–D4 + 结构 + 判据可执行性），否则人类总能再挑语义项（D5/D6）⟹ `λ` 恒 ≈0、
**测的不是机检质量**。**先验（两计划，`n=2`）**：`λ̂ = 0.0`（Laplace 平滑 0.33）⟹ 落"偏松"带，与「v1 对 6 处 +15 全假阴」一致；
阈值 `0.9 / 0.7` 的**量级站得住**，但 `n=2` **只能用先验判方向，不能用先验开门**。v2 落地后复测：机检类漏检归零 ⟹ `λ → 1`，
连续 ≥10 轮无漏检才把 §2.2 阈值改为实测值。
